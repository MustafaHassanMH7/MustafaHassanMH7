# GitHub'a Yükleme

Bu klasör doğrudan yeni bir GitHub repository'sinin kökü olarak kullanılabilir.

Önerilen repository adı:

```text
stm32-radiolink-sbus-usb-joystick
```

GitHub'da yeni boş repository oluşturduktan sonra bu klasörün **içeriğini** root'a yükleyin. `README.md` repository ana sayfasında otomatik görünür.

Büyük generated/debug klasörleri `.gitignore` ile dışarıda tutulmalıdır. `firmware/STM32_Project` içindeki kaynak ve gerekli proje dosyalarını koruyun.
