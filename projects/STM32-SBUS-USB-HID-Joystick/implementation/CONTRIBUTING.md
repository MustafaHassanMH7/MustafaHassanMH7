# Katkıda Bulunma

Bu repository'nin temel amacı doğrulanmış AT9S Pro + R9DS + NUCLEO-F303RE kurulumunu tekrar üretilebilir halde tutmaktır.

Pull request gönderirken:

1. Değişikliğin hangi donanım üzerinde test edildiğini yazın.
2. Firmware değiştirdiyseniz build sonucunu ekleyin.
3. Pin/wiring değiştirdiyseniz şemayı güncelleyin.
4. README ile gerçek firmware arasında çelişki bırakmayın.
5. Başlangıç rehberini gereksiz teknik detayla zorlaştırmayın; derin teknik açıklamayı `docs/07-teknik-detaylar.md` içine koyun.
